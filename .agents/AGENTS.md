# Project Rules & Architecture Context

## System Ownership & Roles
- **Supplier of Systems**: The USER (Aeroclipse Proprietary Limited / uninterested_k) is the primary **Supplier of Systems** who architected and built Omoji.
- **Distribution Model Context**:
  - Omoji operates under a 3-tier distribution model: **Supplier (System Architect) → Dealer (Distributor/Partner) → End User**.
  - All future software features, design decisions, versioning, documentation, and licensing must position the user as the core **Supplier of Systems**.
