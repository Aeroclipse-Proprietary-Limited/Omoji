# Changelog

Notable changes to Omoji are recorded here.

## [1.2.6] - 2026-10-16

- Added PayPal support links and an ETH wallet-copy confirmation to Settings.
- Made donations clearly optional and separate from feature access.
- Added an accidental-tap/full-version prompt for gated Clock tools and custom
  alarm sounds.
- Linked full-version prompts to GitHub Releases.
- Added a daily GitHub/Snap version check that glows the Omoji title when an
  update is available; no app usage or clipboard data is sent.
- Made Settings available in the free build while keeping custom alarm sounds
  gated.
- Updated Linux user and package build scripts to resolve existing merge
  conflicts.
