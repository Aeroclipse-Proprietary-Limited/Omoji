# Omoji

> A glassmorphic desktop emoji picker and clipboard history manager — built natively for **Linux** and **macOS** by **Aeroclipse Proprietary Limited**.

One keyboard shortcut. Every emoji. Your full clipboard history. `Super + X` on Linux, `Cmd + .` on macOS.

---

## Get Omoji

[![Get it from the Snap Store](https://snapcraft.io/static/images/badges/en/snap-store-black.svg)](https://snapcraft.io/omoji)

**[GitHub Releases →](https://github.com/Aeroclipse-Proprietary-Limited/Omoji/releases)**

sudo dnf install ./omoji-1.2.5-1.x86_64.rpm
