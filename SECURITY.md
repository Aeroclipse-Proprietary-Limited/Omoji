| -------- | :-------: |
| 1.2.x    |     ✅     |

| 1.0.x    |     ✅     |
| < 1.0.0  |     ❌     |

---

## Reporting a Vulnerability

Please **do NOT open a public GitHub issue** for security vulnerabilities.

Report all security concerns privately through our website:

**🌐 [aeroclipse-bw.web.app](https://aeroclipse-bw.web.app)**

When reporting, please include:

1. A clear description of the vulnerability (written note or `.txt`, `.pdf`, `.csv`)
2. Steps to reproduce or a proof-of-concept (screenshots, code snippet, or screen recording)
3. The potential impact if exploited — attach a certified affidavit where applicable

---

## Our Response Process

| Stage          | Timeline                    | Description                                                     |
| -------------- | --------------------------- | --------------------------------------------------------------- |
| Acknowledgment | Within **48 hours**         | We confirm receipt and assign the report for review             |
| Triage & Patch | Within **14 business days** | We investigate and develop a fix                                |
| Disclosure     | Upon patch release          | A new release and security advisory are published               |

### Responsible Disclosure Reward

Valid, previously unknown vulnerabilities that lead to a patch are rewarded with **BWP 4,000.00** as a thank-you for keeping Omoji and its users safe.

## Security Tips for Users

- Install Omoji from the [official Snap Store](https://snapcraft.io/omoji) or [GitHub Releases](https://github.com/Aeroclipse-Proprietary-Limited/Omoji/releases) only
- Keep your installation up to date
- Use **Privacy Mode** when handling sensitive data
