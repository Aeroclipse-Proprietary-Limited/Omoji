> Omoji is a human-driven project. We take the security of our users seriously and appreciate every responsible disclosure.

## Reporting a Vulnerability

We kindly ask that you **do NOT open a public GitHub issue** for security vulnerabilities. Public disclosure before a patch is available puts users at risk.

Instead, please report vulnerabilities responsibly through the private channel below.

### How to Report

Send your security report directly to the maintainer:

**📧 Email:** [godlyttn@outlook.com](mailto:godlyttn@outlook.com)

To help us investigate and resolve the issue as quickly as possible, please include:

1. **A clear description** of the vulnerability — written note or a digitized document (`.txt`, `.pdf`, or `.csv`).
2. **Steps to reproduce** — a detailed reproduction path or proof-of-concept (e.g. screenshots, a code snippet, or a screen recording).
3. **Potential impact** — a concise assessment of what could be exploited and the severity if left unpatched. Please attach an affidavit (certified) where applicable.

---

## Our Response Process

We are committed to handling every report with transparency and urgency.

| Stage           | Timeline              | Description                                                                 |
| --------------- | --------------------- | --------------------------------------------------------------------------- |
| Acknowledgment  | Within **48 hours**   | We confirm receipt of your report and assign it for review.                 |
| Triage & Patch  | Within **14 business days** | We investigate the issue and work towards a fix.                      |
| Disclosure      | Upon patch release    | A new release is published alongside a security advisory detailing the fix. |

### Responsible Disclosure Reward

As a token of our appreciation for helping keep Omoji secure, a **BWP 4,000.00** reward is offered upon successful disclosure and patch of a valid, previously unknown vulnerability.

---

## Scope

The following are **in scope** for security reports:

- The Omoji desktop application (Linux & macOS)
- Clipboard data handling and privacy controls
- Privilege escalation or local file system access
- Data exfiltration or unauthorized network communication

The following are **out of scope**:

- Issues already publicly known or previously reported
- Vulnerabilities in third-party dependencies (please report those upstream)
- Social engineering attacks

---

## Security Best Practices for Users

- Always install Omoji from the [official Snap Store listing](https://snapcraft.io/omoji) or [GitHub Releases](https://github.com/Aeroclipse-Proprietary-Limited/Omoji/releases).
- Keep your installation up to date to receive the latest security patches.
- Enable **Privacy Mode** within the app to pause clipboard tracking when handling sensitive data.
