# Contributing to Omoji

**Omoji** is open source and built by [Aeroclipse Proprietary Limited](https://aeroclipse-bw.web.app).

> You can build it yourself — or you can build it *with* us.

---

## Build It Yourself

Omoji is yours to explore. Clone the repo, build the full unlocked version, and use it freely.

```bash
git clone https://github.com/Aeroclipse-Proprietary-Limited/Omoji.git
cd Omoji && flutter pub get
flutter run -d linux   # or -d macos
```

Before opening a pull request, run:

```bash
flutter analyze && flutter test
```

Branch → build → PR against `main`. Keep changes focused and describe what you tested.
